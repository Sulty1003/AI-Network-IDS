# AI-Based Network Intrusion Detection System (NIDS)

## Overview
This project is an AI-based Network Intrusion Detection System developed in Python. It monitors network traffic and uses network analysis and machine learning to identify anomalous behavior.

## Features
- Real-time network packet monitoring
- TCP, UDP, and ICMP analysis
- Network feature extraction
- Rule-based intrusion detection
- Machine-learning anomaly detection
- Alert generation and logging
- Network traffic visualization

## Technologies Used
- Python
- Scapy
- Pandas
- NumPy
- Scikit-learn
- Isolation Forest
- SQLite
- Streamlit

## How It Works
Network Traffic → Packet Capture → Feature Extraction → Rule-Based Detection / AI Model → Anomaly Detection → Alerts
